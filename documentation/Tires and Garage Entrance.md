# Tires and garage entrance

Garage / Tune / Tires adjusts front and rear grip independently from 0.40x to 3.00x. A value of 1.00x uses the imported tire coefficients. Both wheels on an axle are adjusted together; mixed values stay untouched until edited. Reset Both Axles prepares 1.00x drafts. Apply, then Save Car. Chassis presets replace grip when selected, so choose a preset before fine-tuning tire grip.

The garage uses Unity Y-up/Z-forward coordinates and a named KDAEntrance transform at the door. Its F8 approach zone is in front of that door, 0.25-18 metres outward with the scaled half-door width plus three metres of lateral allowance. The car must be landed, unpacked, below 0.75 m/s and outside warp/pause. Drive Out uses the same outward direction and a seven-world-metre gap. See KDA World Garage.md for placement, session and migration instructions.

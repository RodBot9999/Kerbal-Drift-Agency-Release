# Package layout

Runtime: V1.0 / kda25. Converter: V2.0 / kda12.

- GameData: KDA runtime, optional rover ECU and optional world garage.
- Ships/SPH: included Lizard GT and finished Rabbit Rally x craft.
- Converter: offline Windows car converter.
- source: corresponding code, asset build inputs, tests and build instructions.
- documentation: player guides, technical reference, AI prompts and release notes.
- LICENSES: full software licenses and third-party notices.

Copy GameData contents into KSP/GameData. Copy craft into your save's Ships/SPH.
Download external dependencies using the README links. Keep matching source
available with distributed converter binaries. See LICENSE.md and CREDITS.md.

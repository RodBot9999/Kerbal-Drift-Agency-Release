# Project governance

Kerbal Drift Agency is maintained by Roderic Systems. **@RodBot9999 is the
project owner, sole repository administrator and official release publisher.**

## Decisions and contributions

The owner makes the final decision on project scope, roadmap, design, accepted
contributions, releases and repository permissions. Community feedback and pull
requests are welcome; submitting a suggestion or contribution does not guarantee
acceptance, a release date or maintainer access.

Community changes are proposed through forks and pull requests. All files are
assigned to @RodBot9999 in [CODEOWNERS](.github/CODEOWNERS). Changes to `main`
require an approving owner review, with approvals dismissed when reviewable
changes are pushed. The owner has an explicit review-rule exception for solo
maintenance, including their own pull requests and direct updates. This exception
does not bypass the separate rules blocking force pushes or deletion of `main`.

See [CONTRIBUTING.md](CONTRIBUTING.md) before submitting changes or assets.
Contributors retain copyright in their contributions; acceptance does not
transfer copyright to the owner.

## Official releases

The official repository is
[RodBot9999/Kerbal-Drift-Agency-Release](https://github.com/RodBot9999/Kerbal-Drift-Agency-Release).
Only the owner publishes official releases and creates repository tags. Existing
tags are protected against updates and deletion, including by the owner under
the active rules. Corrections should receive a new version and tag.

Public visitors can report issues and propose pull requests, but cannot merge
changes, publish releases or change repository settings. No additional write or
administrative access is granted by contributing.

## Licenses and unofficial versions

Repository governance controls this official project; it does not change the
permissions in [LICENSE.md](LICENSE.md), [ASSET-LICENSES.md](ASSET-LICENSES.md)
or upstream licenses. Compliant forks and redistribution remain permitted under

Unofficial versions must not imply that they are an official release or endorsed
